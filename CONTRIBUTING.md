# Contributing to MOONRUN

Thanks for helping improve this original, open-source game.

## Quick start

1. Fork the repository and create a descriptive branch.
2. Open `index.html` in a browser, or run `python -m http.server 8000 --bind 127.0.0.1`.
3. Make a focused change. Avoid adding external dependencies unless necessary.
4. Test keyboard and mobile controls, restart, pause, collision, and the full 60-second game.
5. Open a pull request with screenshots for visual changes.

## Good first contributions

- Better accessibility, keyboard focus and motion settings
- Balance tweaks and bug fixes
- More original visual effects and sounds
- Gamepad support
- Documentation and screenshots
- Optional, privacy-friendly accessibility or language settings

## Rules

- Only contribute code and art you created or have rights to redistribute under compatible terms.
- **Do not upload Nintendo assets or third-party game ports without explicit permission.**
- No wallet connection, token-trading functions, advertisements, telemetry or tracking without project-owner approval and explicit disclosure.
- Never commit passwords, private keys, API secrets or wallet seed phrases.
- Keep the game playable offline and without dependencies when possible.
- By submitting a contribution, you agree it can be distributed under this repository's MIT License.

## Reporting bugs

Open an issue with browser, operating system, reproduction steps, expected behavior and actual behavior. Do not include sensitive information.

## Community expectations

Be respectful, welcome first-time contributors, and avoid harassment or personal attacks.
